# Python Mini Projects

A collection of small, independent Python practice projects.

## Projects

### Jarvis (Voice Assistant)

A basic voice-controlled assistant using speech recognition and text-to-speech.

- Listens for a wake word ("alexa") via microphone
- Recognizes spoken commands and opens common websites (Google, YouTube, LinkedIn, Facebook)
- Built with speech_recognition, pyttsx3, and webbrowser
- command.txt contains a sample log of test voice commands

Run with:

    python Jarvis/main.py

### Private-MSG (Text Obfuscator)

A simple word-scrambling encoder/decoder for casually obscuring short messages.

- Encoding: adds random 3-letter padding to each word and rotates its first character
- Decoding: reverses the process to recover the original message
- Not cryptographically secure — intended as a fun text scrambler, not real encryption

Run with:

    python Private-MSG/Private_MSG.py
